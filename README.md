## Open-source work

### [WARP: Web Answer Retrieval Protocol](https://github.com/EricStr8/web-answer-retrieval-protocol)

I created **WARP**, an experimental publishing architecture that connects concise, publisher-authored answers to related questions and visible supporting evidence.

WARP uses stable answer anchors, optional fan-out questions, evidence targets, and aligned structured data to make important information easier to reference and verify. It's a **proposed, experimental approach**, not a search-engine standard or a guarantee of AI citations.

[Explore the GitHub repository](https://github.com/EricStr8/web-answer-retrieval-protocol) · [Read the specification](https://ericstrate.com/warp/)
